    六种真正不同的基础设计语言

    主界面不是聊天页，也不是 IDE。它是 文档中心：浏览 Node、阅读/轻编辑 Markdown，并在当前上下文处理 agent 协作交互。

    必须成立的三区

    1. Node 导航 — 每项是有正文的真实 Node，不是文件夹。
    2. Markdown 多 Tab — 中心工作面，阅读柱与舒适留白。
    3. Inspector / 待处理 — agent question、A2A、tool、Delivery。

    MVP 取舍

    displayName 主显示，immutable id 次级弱化。默认展开一条 agent question；其余可渐进展开。审美成熟、可长期使用，而不是炫技。

    技术标识如 cx-352t7n 仅在属性区以等宽弱化出现，不主导首屏。本预览内联真实 built styles.css（commit cd3db99），DOM 对齐 index.html 地标。

    视觉纠偏验收点

    • 无全宽 topbar；workspace/chrome 入口在左栏弱化。
    • 中栏是文稿台，非 dashboard card。
    • 右栏是检视册分节，非三张同质圆角大卡。
