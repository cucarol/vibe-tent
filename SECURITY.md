# Security Policy

Tent controls which project context an agent may read or write. Permission-boundary bugs should therefore be treated as security issues.

Please report suspected vulnerabilities privately to the repository owner instead of opening a public issue. Include a minimal reproduction, affected version or commit, and the expected versus actual readable/writable scope.

Until a public security contact is configured, use the private contact method exposed by the repository hosting account. Do not include real vault contents, credentials, manifests, or private workspace paths in a report.
